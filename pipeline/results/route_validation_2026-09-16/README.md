## 运行与恢复

`runner.pid`、`publisher.pid` 记录本轮启动的进程。`runner.lock` 防止重复队列；`queue.json` 每几秒写心跳。
确认进程命令行后，对 runner PID 发送 SIGTERM 会让它结束当前自己的 worker/editor，保留已有结果。不要杀网页进程或其他 UE 会话。
在没有其他 UnrealEditor 的情况下，重新执行运行目录 `python3 -u run.py` 可跳过已完成状态并继续。终态失败不会自动反复重试；修复后先把该地图原目录归档，再安排重新验证。
`publish.py` 使用 `/opt/pytorch/bin/python`，只读取结果、生成路线图与静态网页状态，不连接 UE。
