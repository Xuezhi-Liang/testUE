# 录制规格 v1（冻结于 2026-09-17）

模板 `tasks/longvideo_template.json` 的 `spec_version` = `v1-2026-09-17`，SHA-256 `87c95ce4b3a57d52…`。每集的任务文件和 `capture_summary.json` 都带这个版本号；要改任何一项就升版本，不悄悄改。

## 1. 单位与范围

- **一张关卡 = 一个地图 = 一集。** 资源包只是采购单位。
- 范围：交付的 442 张关卡里真正的可录场景 147 张，当前可直接录 100 张（规划页实时）。
- Dubai、Lyra、Factory Collection 单独立项，不在本规格内。

## 2. 每集怎么走：两遍

| | 第一遍：覆盖遍 | 第二遍：填充遍 |
|---|---|---|
| 路线 | 一次随机覆盖走法，每条路至少走一次 | 从第一遍终点重抽一次覆盖走法，顺序不同，同样走遍 |
| 风格 | stroll / survey / inspect 每 45 m 轮换 | 整遍 study（段 2.5–5 m，倒退 30%，后退 35%，看 100%，扫 90%） |
| 配速 | 按预算 97% 配速，落后先保覆盖 | 无约束 |
| 折返 | 有 | 有 |
| 耗时 | 一遍估计 | 约 2× 第一遍 |

`target_passes` 2，`max_duration_s` 0（不封顶），不切分片。分片表另写 2× 估计的失控保护上限。成片按一遍估计的 3× 算。

## 3. 路线怎么来

1. **起点**：候选起点文件 → 射线找地面 → 合成导航网 → 投影；新图用 recover_start。
2. **只录有东西的地方**：`content_buffer_m` 10、`content_mode` dense。离内容 10 m 以外的可走面在细化前去掉；内容 = 密度核心（12 m 内障碍占比 ≥6%）加 ≥20 m² 的footprint，另加引擎静态网格包围盒（验证中）。
3. **选区域**：剪完后中心线最长的区域。
4. **中心线**：离边界 ≥90 cm 的部分细化，20 cm 重采样，7 点平滑，重算弧长轴。
5. **剪枝**：胶囊（r 40、h 176 cm）沿路每 40 cm 扫，扫不过的路删，碎片丢。离地间隙平坦街区 6 cm、有台阶的图 45 cm（分片表逐图）。
6. **覆盖走法**：路口随机挑未走的路，走完去最近的有未走路的路口。
7. **折返**：中位数 300 s 抽间隔（±25%），上限 420 s，回走 10–25 s，两次掉头 180°。
8. **重绕**：有碰撞的地方划禁区换路，最多 4 次，仍不干净拒录。

## 4. 运动参数（全固定）

| 项 | 值 |
|---|---|
| 步速 | 1.0 m/s 匀速，每帧 100/24 cm，无加减速；前进、倒退、后退、折返一律 |
| 转速 | 45°/s 匀速，每帧 1.875°；左右转、抬头、低头、回正一律 |
| 俯仰限 | 低头 30°，抬头 15° |
| 眼高 / 视场角 | 1.7 m / 90° |
| 胶囊 | 半径 40 cm，半高 88 cm，走廊净宽 90 cm |
| 帧率 | 24 fps |

按种子随机的只有：风格顺序、每段路长、看和扫的幅度与停留、倒退是否发生、折返时刻和回走时长。

## 5. 动作配比目标带（帧数占比）

前进 26–42%，倒退 10–20%，左转 6–15%，右转 6–15%，抬头 8–18%，低头 7–16%，停留 4–14%。
配比是走出来的统计量，冻结时调参器用五个旋钮推进带内；验证阶段只报告不否决，录制的两遍合起来判。

## 6. 渲染

| 项 | 值 |
|---|---|
| 抗锯齿 | TAA 2×：`r.AntiAliasingMethod 2`，200% 历史分辨率，quality 2，当前帧权重 0.04，8 抖动 |
| 渲染 / 输出 | 2560×1440 渲染，2×2 平均到 1280×720 |
| 历史 | history_mode 4：捕获器显式开 TemporalAA，保留视图状态，起始位姿实际渲染 32 帧预热 |
| Lumen | 工程默认；屏幕探针下采样 8 |
| 雾 / 各向异性 / mip / 锐化 | 雾格 8/128，16×，0，0 |
| 运动模糊 | 关 |
| 曝光 | auto_instant（关适应延迟的关卡测光，亮度只由当前帧决定），局部曝光 shadow 0.65 / detail 1.0 |
| 光照 | fill：保留作者灯光，替换天光，倍率每图自动校准（1/1.5/2/3/4 中最小达标者），录制期间固定 |

完整 cvars：

```ini
r.AntiAliasingMethod 2
r.TemporalAA.HistoryScreenPercentage 200
r.TemporalAA.Quality 2
r.TemporalAACurrentFrameWeight 0.04
r.TemporalAASamples 8
r.Lumen.ScreenProbeGather.DownsampleFactor 8
r.VolumetricFog.GridPixelSize 8
r.VolumetricFog.GridSizeZ 128
r.MaxAnisotropy 16
r.MipMapLODBias 0
r.Tonemapper.Sharpen 0
```

旧 TSR 2× 在 `tasks/tsr_2x_previous_default.json`，回退必须写进批次清单。

## 7. 输出

| 输出 | 格式 |
|---|---|
| RGB | 每帧 JPEG q92，1280×720 |
| 深度 | 每帧 EXR float16，R 通道线性米，原生分辨率，无效 −1，最远 1000 m，无抗锯齿无时域处理 |
| 位姿 | 每帧 x/y/z（cm）、yaw/pitch/roll（度）、动作标签 |
| 折返 | 每次事件的起止帧、回走秒数与米数、掉头角 |
| 元数据 | 任务文件、冻结路线、补光校准报告、`capture_summary.json`（实际 cvars、配比、spec_version） |
| 预览 | H.264 CRF 18 网页视频，不是训练数据 |

## 8. 九道门槛，录前录后同一套

单帧位移 < 50 cm；单帧转速 ≤ 67.5°/s；俯仰不超限；全程无碰撞无穿透；深度探针无异常；覆盖率 100%；配比在带内；折返节奏达标；步速钉住（实测中位数与 p95 在 1 m/s ±2%）。任一不过拒录。

## 9. 运行规则

- 一台机器一个编辑器，每张图重启，绝不重连 UnrealCV。
- 拉取队列：S3 条件写原子认领，认领每 4 分钟心跳，30 分钟无心跳才可接管。
- 首次连接等编辑器日志安静 45 s，上限 900 s，重图 2400 s。
- 机时按实时 2.5 倍算。
- 判断某集用了什么参数，以它自己的 `capture_summary.json` 为准。

## 10. 本版未包含、下一版候选

- 引擎静态网格包围盒作为"内容"来源（本机验证中）。
- 剪枝时沿路在眼高做可见性射线（植被挡视线不挡胶囊）。
- 深度探针从每 60 帧加密到每 6 帧。
- 验证会话冻结动态物体。
